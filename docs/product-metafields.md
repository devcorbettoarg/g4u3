# Metacampos de producto G4U

Crear estos metacampos en **Shopify Admin → Configuración → Datos personalizados → Productos**. Todos deben ser de tipo **Texto enriquecido** para mantener listas, negritas y enlaces en el PDP.

| Nombre | Namespace y clave | Uso en PDP |
| --- | --- | --- |
| Detalles del producto | `custom.product_details` | Acordeón “Detalles del producto” |
| Ingredientes | `custom.ingredients` | Acordeón “Ingredientes” |
| Información nutricional | `custom.nutrition` | Acordeón “Información nutricional” |
| Conservación | `custom.storage` | Acordeón “Conservación” |
| Envíos y entregas | `custom.shipping` | Acordeón “Envíos y entregas” |
| Subtítulo | `custom.subtitle` | Bajada en las tarjetas del PLP |

Para cada producto, completar también: título, descripción breve, precio, SKU, peso, variantes, etiquetas comerciales, imágenes (mínimo 3) y colección. La galería del PDP muestra thumbnails automáticamente desde la segunda imagen.

No cargar afirmaciones nutricionales, ingredientes ni valores de tabla sin la ficha técnica aprobada del producto.
